## Idriç observations (source review only)

- Current SSH sketches use indexed session states and explicit algebraic outcomes. The new task-specific sketch distinguishes intended destination from presented key, trust lookup from user decision, stdout from stderr, EOF from process exit, and remote byte reads.
- Existing Error.idric collects many SSH conditions in one SSHError type. The new sketch proposes class distinctions without asserting that the existing type is wrong or imposing one universal error representation.
- Mail sketches keep mbox source intervals and escaping evidence distinct from RFC header/MIME interpretation.
- Provenance treats Message-ID as present, absent, or malformed evidence; no deduplication rule is proposed.
- Restart state marks lost acknowledgement as uncertain and identifies reconciliation before retry.
- Streaming tests a bounded-step composition. It does not materialize a complete mailbox.

The first draft runs exposed three sketch-authoring diagnostics, all corrected without changing the intended domains: the indexed PacketInput declaration needed the constructor-bearing where form (Expected 'where'); nested files had to be checked from their source directory so the module name matched the path; and the SSH file had duplicate RemoteEOF constructors. The final nine mail sketches pass. These were syntax/path/name errors, not compiler deficiencies. No Idriç limitation was confirmed by the completed mail checks. Compiler repair remains outside scope.
